## 🛠 Технические детали реализованных датчиков

### 1. Компас (Magnetometer)

**Реализованные функции:**
- ✅ Поддержка HMC5883L, QMC5883L
- ✅ I2C интерфейс (адрес 0x1E / 0x0D)
- ✅ Внутренняя обработка сырых данных X/Y/Z (не передаются в UI)
- ✅ Компенсация Hard Iron (смещение)
- ✅ Фильтрация скользящим средним (10 выборок)
- ✅ Обработка перехода через 360/0 градусов
- ✅ Магнитное склонение (10° для Москвы)
- ✅ Частота опроса: 2 Гц

**Файлы:**
- `src/core/sensors/compass_ultrasonic.hpp` (Compass класс)
- `src/core/sensors/compass_ultrasonic.cpp` (реализация)

**API:**
```cpp
float getHeading();  // Возвращает курс 0-360°
bool readRaw(int16_t& x, int16_t& y, int16_t& z);  // Для калибровки
void setCalibration(float min_x, float max_x, ...);  // Калибровка
```

### 2. Ультразвук (Ultrasonic)

**Реализованные функции:**
- ✅ Поддержка HC-SR04
- ✅ GPIO интерфейс (Trigger=17, Echo=27)
- ✅ Диапазон: 2 - 400 см
- ✅ Защита от таймаутов
- ✅ Частота опроса: 2 Гц

**Файлы:**
- `src/core/sensors/compass_ultrasonic.hpp` (Ultrasonic класс)
- `src/core/sensors/compass_ultrasonic.cpp` (реализация)

**Зависимости:** wiringPi (требуется установка на RPi)

### 3. WiFi Quality (RSSI)

**Реализованные функции:**
- ✅ Чтение RSSI из `/proc/net/wireless`
- ✅ Конвертация dBm в проценты (0-100%)
- ✅ Передача через WebSocket как `wifi_quality`
- ✅ Отображение в веб-интерфейсе

**Файлы:**
- `src/core/system_monitor/system_monitor.cpp` (метод `readWifiQuality()`)

## 🚀 СЛЕДУЮЩИЙ ШАГ: P2-10 Облегченные автономные режимы

**Приоритет:** ВЫСОКИЙ (Фаза 4, задача 1)  
**Оценка:** 12 часов

### План реализации:

#### 1. State Machine (Конечный автомат) - 3 часа
**Состояния:**
- `IDLE` - Ожидание команды
- `MANUAL` - Ручное управление (по умолчанию)
- `PATROL` - Патрулирование по точкам
- `AVOID_OBSTACLE` - Объезд препятствия
- `HOLD_HEADING` - Удержание курса

**Файл:** `src/core/autonomy/autonomy_manager.hpp`

#### 2. Алгоритм "Стоп-кран" - 2 часа
- Мгновенная остановка при `ultrasonic < 20cm` в любом режиме
- Приоритет над всеми режимами
- Визуальное предупреждение в UI

**Файл:** `src/core/autonomy/obstacle_avoidance.cpp`

#### 3. Режим "Удержание курса" - 3 часа
- Использование PID-регулятора (упрощенного)
- Поворот шасси на заданный угол по компасу
- Точность: ±5°

**Файлы:**
- `src/core/pid_controller.hpp` (новый легкий класс)
- Интеграция в `autonomy_manager.cpp`

#### 4. Режим "Обход препятствия" - 2 часа
- Если препятствие спереди -> Стоп
- Поворот на 90°
- Движение 2 секунды
- Возврат к исходному курсу

**Файл:** `src/core/autonomy/obstacle_avoidance.cpp`

#### 5. Интеграция в UI - 2 часа
- Кнопки активации режимов в веб-интерфейсе
- Отображение текущего состояния автомата
- Индикатор активного режима

**Файл:** `static/index.html` (добавление панели автономности)

## 📝 Заметки

### Исключено из текущего плана:
- ❌ **Безопасность** (аутентификация, HTTPS) - не приоритетно для локальной сети
- ❌ **Видеопоток** - требует отдельной оптимизации для RPi 2B
- ❌ **ML/CV функции** - требуют RPi 4/5 или Jetson Nano

### Требования к железу:
- **RPi 2B:** Обязательно охлаждение (радиатор + вентилятор)
- **Wi-Fi:** Рекомендуется USB адаптер с внешней антенной
- **Камера:** VPU RPi 2B слабый, только скриншоты
- **Датчики:** I2C компас, GPIO ультразвук

### Команды для развертывания:
```bash
# Установка зависимостей
sudo apt-get install libpigpiod-if2-1 wiringpi pigpio-tools

# Запуск демонов
sudo pigpiod
sudo systemctl enable robo_chassis_core

# Сборка без GPIO (для тестирования на PC)
cmake .. -DUSE_PIGPIO=OFF
make -j4
```
